# Starfield Shaders vendor demo archive

The original Starfield Shaders demo scenes and camera scripts are kept here, outside Unity's `Assets/` folder, as reference material.

They were authored for an older Unity version and trigger scene-upgrade/import warnings in the current Star Vortex mod project (including obsolete Main Camera components and generated `Settings.lighting` import failures). The runtime/editor Starfield Shaders code and shaders remain under `Assets/StarfieldShaders/`.
