These are the base game ScriptableObjects imported for reference.
DO NOT edit these directly - changes here have no effect.

To override a base game asset:
  1. Right-click the asset you want to change
  2. Select Edit > Duplicate (Ctrl+D)
  3. Move the copy to your own mod folder
  4. Edit the copy
  5. Assign it to your AssetBundle
  6. The mod version replaces the original at runtime (matched by name)
